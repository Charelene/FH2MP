# Chat link v1 (shim <-> chat core, loopback TCP): one frame per line, "<name> <hex>". All little-endian.
# Frame: u32 length of what follows (2 + payload, at most 65536), u16 type, payload. Unknown types are skipped by their length.
# 1 HELLO       shim->core  u16 version, 32 bytes secret (from fh2mp-chat.txt), u32 game pid, u64 game window, u64 xuid (0 unknown)
# 2 WELCOME     core->shim  u16 version, u8 flags (bit 0: the Guide can be shown)
# 3 PAD         shim->core  u16 XInput buttons (0x0400 = Guide), u8 left trigger, u8 right trigger, i16 lx, ly, rx, ry (only while the Guide is open)
# 4 GUIDE       shim->core  u8 cause (1 Guide button held 1 s, 2 keyboard key, 3 the game asked to invite friends): open or close the Guide
# 5 GUIDE_STATE core->shim  u8 open (1: the shim keeps the pad from the game and sends PAD)
# 6 WINDOW      shim->core  i32 x, y, width, height of the game's client area in screen pixels, u8 flags (bit 0 fullscreen, bit 1 minimized)
# 7 GAME_STATE  shim->core  u8 online, u8 mode (0 menus, 1 Free Roam, 2 event, 3 Road Trip, 4 Car Meet), u16 players in the world
# 8 OPEN_PAGE   shim->core  u8 page (1 invite to game), u16 length, UTF-8 argument (at most 512 bytes)
# 9 BYE         either      u8 reason (1 game closing, 2 core closing, 3 protocol error)
