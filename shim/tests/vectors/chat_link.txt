# Chat link v2 (the in-game Guide <-> Encore, loopback TCP): one frame per line, "<name> <hex>". All little-endian.
# Frame: u32 length of what follows (2 + payload, at most 65536), u16 type, payload. Unknown types are skipped by their length; a length
# over 65536 or a payload that does not decode exactly is a protocol error (BYE 3, close). str: u16 byte length, that many UTF-8 bytes (no
# terminator), at most 8192 (the sender cuts longer text at a UTF-8 boundary). Encore names its port and secret in the game's
# data/bin/fh2mp-chat.txt ("port=<decimal>", "secret=<64 lowercase hex>").
# 1  HELLO     Guide->Encore  u16 version (2), 32 bytes secret, u32 game pid, u64 xuid (the session's, 0 unknown)
# 2  WELCOME   Encore->Guide  u16 version (2), u8 flags (bit 0: DMs are end-to-end now), u64 xuid Encore is signed in as (0 unknown)
# 9  BYE       either         u8 reason (1 game closing, 2 Encore closing, 3 protocol error, 4 refused: secret, version or account)
# 10 OPEN      Guide->Encore  str chat id (a friend's xuid in decimal, or "club")
# 11 CLOSE     Guide->Encore  (none) the open conversation closed
# 12 SEND      Guide->Encore  u32 request id, str chat id, str text (1-2000 characters)
# 13 READ      Guide->Encore  str chat id, i64 max_id (the newest message seen)
# 20 CHATS     Encore->Guide  u16 count, then per conversation: str id, str title, str last text, i32 unread, i64 last incoming id, u8 flags
#                             (bit 0 end-to-end, bit 1 club)
# 21 MESSAGES  Encore->Guide  str chat id, u16 count, then per message oldest first: i64 id, u64 sender xuid, str gamertag, str body,
#                             i64 created (seconds since 1970), u8 state (0 incoming unread, 1 incoming seen, 2 sending, 3 sent, 4 read, 5 failed)
# 22 SENT      Encore->Guide  u32 request id, u8 ok (1/0), str why (empty when ok)
# 23 NOTICE    Encore->Guide  u8 kind (1 new DM, 2 new club post, 3 friend on a new PC), str chat id, str title (the sender's gamertag), str text
# The C side is shim/src/chat_link_wire.h (tests/test_chat_link.sh, which also holds the values behind each line; Encore Launcher's Guide
# keeps a copy), the Rust side Encore Launcher's crates/encore-core/src/link_wire.rs; both check their encoder and decoder against these lines.
