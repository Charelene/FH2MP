# FH2MP: Forza Horizon 2 online, back from the dead (sort of)

> **v1.0.0-rc2, a pre-release.** It works, and it is still young: expect crashes, desyncs and rough edges. See the progress table for what
> is and is not there, and the [rc2 release notes](release/notes/v1.0.0-rc2.md) for what changed since rc1.

Microsoft switched off Forza Horizon 2's online services on 2023-08-22. FH2MP brings them back: the **real game
client**, speaking the **game's own network protocol**, to a **replacement server** written from scratch.

![Two game clients in the same Online Free Roam session: each sees the other player's car and name tag, and the Players list shows both](assets/demo-free-roam.jpg)

## Playing

You need a legitimately owned copy of Forza Horizon 2 (Xbox One build 1.0.0.64) running through [Azimuth 0.9.10](https://almost-there-games.itch.io/azimuth).
Then:

1. Download the **FH2MP Launcher** from the [latest release](https://github.com/Charelene/FH2MP/releases/latest): `setup.exe` or the portable zip
   for Windows; `.deb` or `AppImage` for Linux.
2. Start it. It finds Azimuth, installs the shim, and makes your account. **No e-mail, no password:** your account is a secret key kept on your
   computer (in the OS keyring), and you get a recovery code to move it to another machine. Keep that code private.
3. Pick a gamertag and a picture, press **PLAY**.

The launcher keeps the shim up to date (every release is signed; nothing unsigned is ever installed), warns about untested Azimuth versions, shows
how many people are online, and updates itself. On Linux, set the Proton script and prefix once in Settings (or a custom launch command).
Website: [forza.scuffed.af](https://forza.scuffed.af).

**Overall, "find a friend through a Car Meet, play Online Free Roam and an event" is at roughly 70%.** The rest is the long tail.

**Rivals in more detail.** Turn 10 curated the Monthly Rivals events and that content is gone for good, so the server
generates them: each month (or on an admin re-roll) it picks 12 closed circuits, one lap each, with a random restriction
(class, body style, brand, era, drive type, country or a single car), and a time of day and weather on many of them.
The rival is a real player with a ghost when one exists, otherwise a made-up driver with a believable time derived from
the route length and car class. Ghosts upload and play back, getting beaten sends a "beat you" notification under My
Rivals, and each new rotation sends a rival recommendation. Showcase, Festival Routes, My Rivals and rewards work.
Not done: DLC rival pages, the Road Trip rival tab (unchecked). Leaderboards are padded with made-up players so they are
never empty; the Friends filter shows only you for now.

**King and Infection in more detail.** Both are Road Trip events (they need two players, so the destination vote is drawn again when a second
player joins, as long as nobody has voted yet). Since rc2 King also starts from a Free Roam map icon: the server is never told the event type
there, so it reads it from the leader's event options and tells Infection from King by the first hit (new; checked against logged payloads
and tests, not yet against the live server). The client decides what a collision does from the event's own rules and reports it; the server is the referee. At the start
it picks the crown holder (King, one per six players) or patient zero (Infection) at random, applies each reported hit once, sends everybody
the new crown or infection state, ends the event on the time limit (Infection also when everybody is infected) and picks a new holder if
the current one leaves. The game's own HUD does the rest: crown name tag, scoreboard and results. Both modes were seen working with two
clients; with more players, long sessions and the results flow they are untested.

**Paint jobs and tunes in more detail.** Both use the game's own storefront calls. A design or tune shared on one client is stored on the
server (compressed), listed in search, in Recommended Designs and on the Clubs tab, and downloads and applies on another client.
Previews and thumbnails come from the player's own upload, and the car name the game shows for an item is the car id the server sends.

**Car Clubs in more detail.** Clubs follow the rules in the game's own club texts: a unique 3 or 4 character tag, one club per player, one
Leader and up to three Co-Leaders, a size limit, invites, join requests and the noticeboard. The member ladder and the club level board
are computed from the XP members earn after joining. The game has no Club Garage screen in Horizon 2, so shared cars are not
reachable from the game. Some wire values (privacy numbers other than Open, club error codes) are still guesses.

**Friends in more detail.** The game's friends module, presence and gamerpic code all talk to the Xbox social services, so they are
native to the game and only need answers. There is no friend request screen in Horizon 2 (friends live in the Xbox dashboard), so
friendships are made through an admin API for now. "Show Xbox Live gamercard" opens a system overlay that the compatibility layer fakes,
so it cannot be served by this project.

## Other known gaps

- Tested on one setup only (below), with two clients. Real networks, NAT, more players and Windows are unexplored.
- Sessions are lost when the server restarts; clients have to matchmake again.
- No account system yet: a player's id is a local file and the server trusts the id it is given. Fine for testing, not for a public release.
- Gamercards (a system overlay) and the Club Garage (not in Horizon 2's UI) are not available.

## How it works

| Piece | What it does |
|-------|--------------|
| **Azimuth** (third party, not included) | Runs the Xbox One build of FH2 on a PC and stubs every online call as offline. |
| **`launcher/`** | The player-facing Qt launcher: accountless sign-in (Ed25519 key on your machine, server-assigned id), gamerpic, Azimuth version check, shim and self update from signed GitHub releases. |
| **`shim/`** | A small in-process `winmm.dll` proxy. Re-enables real sockets, gives each install its own identity, lets the game's matchmaking and online Car Meet run, completes the QoS, secure-address and token steps, passes launch options, and patches a few gates (for example the Rivals "race this event" check). `shim/fh2dbg.py` is a live debugger client for it. |
| **`server/`** | Python. `fh2mp_server.py` speaks the game's NetV2 UDP protocol (lobbies, worlds, relay; standard library only). `fh2mp_lsp.py` stands in for the HTTP cloud services (Message Center, Drivatars, Rivals, scoreboards, user content, permissions, economy), `xbl.py` for the Xbox Live session, matchmaking and game-server services. The LSP needs `psycopg` 3. |

Everything server-side runs centrally on one VPS. State lives in PostgreSQL: scores, ghosts, Drivatars, notifications, Rivals events
and user-made paint jobs in `public`, and a "game catalog" (game tables, English strings, route geometry, the web-service schemas,
the shipped Drivatars) in the schema `game`. The catalog is built once from your own install with `tools/export_gamedata.py` and
loaded with `tools/load_gamedata_pg.py`; the running server never touches game files, and the catalog is never committed or shipped.
Backups (WAL archiving for point-in-time recovery, hourly/daily/weekly dumps) and restore are in `docs/ops.md`.

The protocol was recovered from the client itself, not from captured Microsoft traffic. No Microsoft or Xbox Live
service is contacted, ever. There was nothing left to sniff.

## Requirements (what it was actually tested on)

- A **legitimately owned copy** of Forza Horizon 2, Xbox One build **1.0.0.64**. No game files are in this repo.
- **Azimuth 0.9.10**. The shim checks its hooks against byte signatures from that build and skips anything that does not match; the launcher tells you if your build is not the tested one.
- **FH2 Extra Options 0.2.98** is the only supported build. The launcher installs it if it is missing (Settings, off switch included); or put its `Azimuth/winmm.dll`, ini and PNG in an `fh2extra` folder next to `azimuth.exe` yourself. The shim chain-loads it.
- To build by hand: `shim/build.sh` (needs `x86_64-w64-mingw32-gcc`) builds `shim/build/winmm.dll`; the launcher does the placing and the Wine override for you. Launcher sources are in `launcher/` (PySide6), release tooling in `release/`.
- Linux with Wine/Proton (tested on Proton-CachyOS 11), and Windows 11 (tested on one PC; rc2 fixes the join bug that kept Windows players on "searching").
- `python3` for the servers; the LSP additionally needs PostgreSQL 16 and `psycopg` 3 (see `docs/ops.md`).
