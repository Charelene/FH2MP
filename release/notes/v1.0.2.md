## Added

- More diagnostic logs and matching Mod Platform dumps in crash reports.
- Detected Redline and NitroSystem clients are matched into the existing flagged pool, including tools started during a session.

## Changed

- Online play uses the server's car database again. Existing car-pack overrides are backed up before replacement and restored for offline play; original game files and car-pack assets are retained.
- Crash reports accept up to 32 MiB of dumps and 8 MiB 
- Crash issues use the first recorded failure and show attachment links without a missing-dump status row.

## Fixed

- A joining car crashing other players when an unsupported engine swap was replaced with stock but incompatible engine sub-parts were retained.
- Missing or wrong-table tire parts reaching other players' car physics.
- Rental class corrections reaching other players but leaving the driver's own grid at R 999.
- Specific crashes while probing a game image during startup, reading missing upgrade torque rows, or opening a missing optional Cinematics directory.
- Windows mod installation failing before loaded DLLs could be replaced, and failure to restore the previous file when replacement failed.
- Race class restrictions being lost across partial settings updates, allowing a C-class car into a B-only grid.
- Live opponent updates being discarded against a timestamp cached before a scene transition, and stale cached physics being replayed afterward.
- Race scores leaking between participants and players outside the event.
- Server race logs showing a lap time as the total race time.
