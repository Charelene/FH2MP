## Fixed

- **Online features off after the game restarted itself.** When the game restarted on its own, for example with Restart now after changing a setting on the Mods page that needs a restart, the launcher took it for the end of the game. The restarted game then went online without your sign-in. NitroSystem's NOS stayed off, and other players didn't see your underglow, lights, doors or horn. The launcher now keeps following the restarted game, so it plays online exactly like the one you started with Play. The same goes for a game started from Azimuth's own window.
- This update has a new launcher (1.4.1); it offers to update itself the next time you open it.
