## Changed

- **FH2 Extra Options 0.6.1** (by RokkuDayo). Games with hundreds of car-pack cars no longer stutter when Drivatars spawn in them, Storm Island's own weather is back in the Change time menu, and championship races come back as one-off races after you finish them with Show All Races on. The launcher installs it the next time you press Play. Your settings stay as they are, and your 0.6.0 `winmm.dll` is kept in the `fh2extra` folder. Weather Control's time lock is still set aside while you're online.
- **A warning before Windows runs out of memory.** When the game's memory use comes close to what Windows can give it, the Guide shows "Memory almost full: restart the game soon", so you can save and restart before the game stops. The launcher also warns at Play when Windows has little memory to spare for a new game, and a crash report that ends this way says so and what to change.
- This update is required: launchers older than 1.4.1 are asked to update before the next Play.

## Fixed

- **Online features off after the game restarted itself.** When the game restarted on its own, for example with Restart now after changing a setting on the Mods page that needs a restart, the launcher took it for the end of the game. The restarted game then went online without your sign-in. NitroSystem's NOS stayed off, and other players didn't see your underglow, lights, doors or horn. The launcher now keeps following the restarted game, so it plays online exactly like the one you started with Play. The same goes for a game started from Azimuth's own window.
- **A crash about 13 seconds after leaving a Car Meet.** When you left a Car Meet, the game still looked up the meet it had just left, found nothing there, and the Guide crashed reading it. The Guide now sees that the meet is gone and the game goes on.
- **An error box that froze the game** when a Guide notification closed. As a toast zoomed out, its icon got smaller than a pixel, and the Guide's text library stopped the game over it. Text and icons that small are now simply not drawn, everywhere in the Guide.
- **The Guide not showing up** next to some other overlays, ShowFPS among them, or when the game started quickly.
- **A crash when the game starts** on some PCs: Azimuth locks part of the game's memory while it starts, and the FH2MP mod crashed when it wrote there at the same moment. It now waits and tries again.
- **A crash in Free Roam with a camera animation.** The game could play a camera animation that had nothing to follow and crash. That camera now stays where it is for that moment.
- **Forza Horizon 3's folder taken for FH2's.** FH3 ships the same game file name as FH2, so the launcher could pick a FH3 folder. It now tells the two apart and finds your FH2 folder. Crashes of FH3 are no longer sent as FH2MP reports.
- **"Your graphics card can't run this"** now says so in the crash report, with what to check (driver, the laptop's high-performance setting, older cards), instead of an unknown GPU.
- **Memory that keeps growing.** On some PCs the game's memory grows by about a gigabyte every few seconds until it stops. When that happens, the FH2MP mod now writes into its log what is filling the memory, so the crash report can show where it comes from.
