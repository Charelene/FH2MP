> **Release candidate 2.** Fixes the Windows "searching forever" bug and adds launcher diagnostics. Please report bugs and feedback in [Issues](https://github.com/Charelene/FH2MP/issues).

FH2MP is an open, community-run replacement for the retired Forza Horizon 2 online services. No lobbies to host, no addresses to share: matchmaking finds players for you.

## What's new in rc2

### Added
- The launcher shows the real reason when it can't reach the server (for example "certificate has expired" or "timed out") and writes failures to `%LOCALAPPDATA%\FH2MP\cache\launcher.log` (Linux: `~/.cache/fh2mp/launcher.log`).
- King events started from a Free Roam map icon now assign the crown. Infection is told apart from King by the first hit.

### Changed
- Launcher connections to the server use IPv4 only.
- If the Windows certificate store causes a certificate error, the launcher retries with its own built-in list of trusted certificates.
- If a system proxy (often set by a VPN or security software) fails, the launcher retries once without it.
- If the reply to registration is lost, the launcher checks whether the account was created before discarding your key.
- A Free Roam circuit race now ends when every player has finished or been cut off, or 30 seconds after the first finisher.
- FH2 Extra Options **0.2.98** is the only supported build. The launcher can install it for you if it is missing (Settings; your own copy is never replaced).
- Linux: the launcher picks the newest Proton it finds and makes its own prefix when no Steam prefix has the game, instead of falling back to the system Wine.

### Fixed
- **Windows: Free Roam stuck on "searching" or "Unable to join session".** The game never binds its UDP socket and relied on the first receive doing it, which Linux allows and Windows rejects, so no packet left the PC.
- Social, Clubs, Rivals and online tiles locked on some PCs: the shim now finds a place to attach on machines where its first choice is taken.
- Free Roam circuit race: the results screen never let you out.
- Free Roam: a player who isn't the party leader got stuck when picking an event.

## Requirements
- Your own copy of **Forza Horizon 2** (Xbox One build 1.0.0.64), run through **[Azimuth 0.9.10](https://almost-there-games.itch.io/azimuth)**. Other Azimuth versions are untested.
- Windows, or Linux with Proton/Wine.

## Install
Download one file below:

| System | File |
|---|---|
| Windows | `FH2MP-Launcher-…-windows-x64-setup.exe` (installer) or `…-portable.zip` |
| Linux, Debian/Ubuntu | `fh2mp-launcher_…_amd64.deb` |
| Linux, anything else | `FH2MP-Launcher-…-x86_64.AppImage` (`chmod +x`, run) |

`fh2mp-shim-….zip` is the in-game part; the launcher installs and updates it for you, you don't need to download it. If you already run rc1, the launcher offers the new shim on its own.

## Known issues
- King and Infection started from a Free Roam map icon are new and have only been checked against logged data and tests; Infection is assumed to be King until the first hit.
- Road Trip only offers King and Infection when at least two players are in the lobby when the vote is drawn.
- Rivals: some leaderboard rows are placeholders, a time under about 28 seconds can hang the game, the selected ghost can revert to the recommended one, and Monthly challenges don't restrict car class yet.
- Speed-trap and PR-stunt boards are placeholders and don't save your result.
- Starting a **Rivals** event can hang on "Setting Up Rivals Event" for some players.
- No packet-loss recovery yet: fine on a good connection, rough on a bad one.
- Traffic is only partly synced between players. Bucket List cars don't show online yet.
- Not done: friends and presence, Convoys, Storm Island / Porsche DLC online.
- The very first load in a fresh Azimuth folder can be slow while it builds its caches.
- One small server: comfortable for roughly 60–100 players.

## Privacy
The server stores your public key, gamertag, picture and IP address. No email, no real name. Nothing is ever sent to Microsoft or Xbox Live.
