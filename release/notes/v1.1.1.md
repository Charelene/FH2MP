## Added

- A setup wizard for new and existing installs, covering game-folder selection, Azimuth installation or update, required mods, Linux support, and account registration or recovery.
- Browser sign-in to itch.io for downloading Azimuth through the launcher, alongside manual ZIP installation.
- Verified installation backups and rollback during Azimuth updates.
- Automatic Proton prefix setup and native Microsoft shader compiler installation on Linux.

## Changed

- Require the supplied combination of Azimuth 1.0.2, FH2 Extra Options 0.3.2, FH2 Mod Platform 2.7.3 and FH2MP 1.1.1.
- Download the signed shim matching the launcher's release instead of following a different release's dependency pins.
- Replace the account ID's Copy text with a copy icon.

## Fixed

- Azimuth 1.0.2's relocated command-line hook preventing multiplayer launch options from being applied.
- Concurrent startup HTTP requests using the default endpoint before the launcher's server settings finish loading.
- Obsolete Extra Options downloads, incomplete plugin updates, and old Azimuth TLS helpers blocking the supported installation.
- Linux game-folder detection missing an existing Steam prefix and using Wine's unsupported shader compiler.
- Duplicate launcher windows and background sign-in retries repeatedly replacing an account's active session.
- Old crash dumps triggering a crash report after a later healthy launch.
- Bonus-board leaderboards showing accumulated XP instead of boards smashed.
- Bonus-board and road-discovery leaderboards retaining totals from an older save instead of updating from the current save.
- Clipped cards at the main window's minimum height, setup spacing, redundant installation clicks, and delayed ZIP validation.
