## Added

- Headlights, turn signals and hazard lights controlled through FH2 Extra Options are now visible to other updated players in multiplayer.

## Changed

- Update the supported combination to Azimuth 1.0.3, FH2 Extra Options 0.3.9, FH2 Mod Platform 2.7.4 and FH2MP 1.1.2.
- Install both platform loaders, including DWrite.dll required by Azimuth 1.0.3. Linux launcher DLL overrides now include dwrite.
- Install Extra Options' updated Garage Revving plugin and complete Weather Control resources while preserving existing INI preferences.
- Reopen setup for installations using the previous dependency set. Azimuth updates keep settings, saves and other mods, with backups and rollback.

## Fixed

- Multiplayer launch arguments following Azimuth 1.0.3's relocated command-line function.
- Existing manually upgraded installations being blocked by an obsolete shared Azimuth TLS helper.
- Incomplete Azimuth archives being accepted without the matching per-title helpers.
- Missing, conflicting or outdated copies of either platform loader passing installation checks.
- Dev launcher profiles retaining the retired localhost server address after updating.

All players need the updated shim to send and see the new lighting state. Signal blink timing remains native to each client. No game files, Azimuth binaries or third-party mods are bundled; setup downloads the pinned mods from their authors.
