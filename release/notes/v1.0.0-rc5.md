> **Release candidate 5.** Please report bugs and feedback in [Issues](https://github.com/Charelene/FH2MP/issues).
> **rc5 is required.** Older launchers and shims are turned away; the launcher updates itself, or download it again from the release page.

## What's new in rc5

### Added
- The launcher tells you what to do when Azimuth stops at "Your graphics card or driver is not supported".
- XP awards are checked: impossible amounts no longer count toward your total or the XP board.

### Changed
- One event at a time per Free Roam lobby: a new race request waits until the running event is over.
- Players who have not loaded an event after 60 seconds are dropped from it, so everyone else can start.
- Cars with parts the game doesn't have appear to other players with stock parts instead of crashing them.
- Class X and R cars no longer appear on Rivals leaderboards.
- Linux: Settings accepts the Proton folder as well as the `proton` script; the launcher no longer falls back to the system Wine.

### Fixed
- Linux AppImage/.deb: "Your graphics card or driver is not supported" on AMD GPUs (#10).
- Linux: "could not start the game: Permission denied" when Proton was set to a folder.
- Rubberbanding in races on busy servers.
- Free Roam events stuck on loading when the host left during the invite, or when two events overlapped.
- Rivals: the #1 player can race again, against their own ghost (no bounty for it).
- Team Forza cars getting their owners kicked.
