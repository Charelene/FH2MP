## Fixed

- **1.3.1 closed healthy games.** Its new memory guard was set up wrongly: on PCs with 14-16 GB of RAM it closed the game while it was still loading, and on high graphics settings the game ran into the guard's memory limit and stopped with "out of memory". The guard no longer closes or limits the game at all. It only measures now, so the logs show what happened if memory ever does run away. Sorry for the hour of crashes.
- **Joining a lobby failed when the lobby was nearly full.** A player whose game had ended kept their seat in the lobby's member list for up to 30 minutes, so a lobby with room looked full to the game and the join gave up after about 20 seconds. Seats are now given back when the game ends, and the matchmaker no longer picks a lobby whose member list is full.
- In the launcher's My setup window, "Session for the game" read "none: the game starts offline" before you pressed Play, which looked like an error. It now reads "none yet: Play makes it".

## Changed

- This update is required: launchers older than 1.3.2 are asked to update before the next Play.
