## Added

- Offline mode for solo play, using the same account save as online play.
- A save manager in Settings: import an Azimuth save into FH2MP or export your FH2MP save back to Azimuth. Every transfer backs up both saves first; you can also select another profile or restore a backup.
- Photo sharing, photo search, and popular and featured photo lists.
- Optional crash reports with a preview of what will be sent and redaction of sensitive log data. Detailed logs and dumps stay private; summaries can be published as GitHub issues when the server is configured for it.
- Website support for browsing lobbies and reporting leaderboard entries.

## Changed

- Save setup now blocks launch when an existing save cannot be copied. Permission failures offer a retry with administrator access.
- The save manager clearly distinguishes Azimuth's default profile from the FH2MP account save shared by online and offline play.
- The launcher installs FH2 Mod Platform 2.7.2 and repairs missing Extra Options settings and legacy TLS-helper installations.
- New gamertags follow Azimuth's naming rules. Older names are adapted for display so they no longer fall back to “Player 1.”
- Name moderation uses configurable administrator blocklists.
- The server preserves the game's built-in economy values by default.
- Stronger connection authentication, session limits, score validation, and release verification.

## Fixed

- Saves not carrying over from some existing Azimuth installations, including permission errors during setup.
- Photo title and description validation returning the wrong number of results and blocking sharing.
- Offline play skipping restoration of a modded car database preserved during online play.
- More lobby crashes caused by invalid or unsupported modded car parts.
- Cars outside a race sharing its collision space, including players who have finished or left the event.
- Free Roam lap-count handling and lap-based race completion.
- Rental cars displaying an incorrect R 999 class on the grid.
- Incorrect leaderboard career levels and Monthly Rivals accepting or offering cars outside the required class.
- Linux file-picker lockups and mod-loader conflicts caused by DLL filename casing.
- Windows updates failing when a running process has loaded a DLL.
- Dev requests reaching the production HTTP host.
- Connection-ticket replay protection failing when its nonce table is full.
- Fixed easter egg.
