> **Release candidate 4.** Please report bugs and feedback in [Issues](https://github.com/Charelene/FH2MP/issues).
> **rc4 is required.** Older launchers and shims are turned away; the launcher updates itself, or download it again from the release page.

## What's new in rc4

### Added
- Outdated launchers and shims are refused with a message that says to update.
- The Windows portable build updates itself from the launcher; the AppImage carries update info for AppImageUpdate.

### Changed
- The launcher sets your in-game name and picture on every start (#3).
- Leaderboards show real players only; made-up rivals are off (#1).

### Fixed
- The game closing for everyone in a lobby when a player's car has an engine part the game doesn't know.
- Monthly Rivals events ignoring their class in the car selector, including events already running (#2).
- "Player 1" instead of your gamertag, and the mod's default picture (#3).
- Update checks failing silently on some Linux setups.
