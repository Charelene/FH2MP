## Fixed

- **A crash when the game starts after you removed a car mod.** A car mod can leave a line in the game's media list that points at a zip file that is no longer there, and the game stopped on it at every start. The FH2MP mod now takes such a line out before the game reads it and keeps the original file next to it as `zipmanifest.xml.fh2mp-<date>.bak`. A list with many missing zips is left alone.
- **Game stops in offline games.** The guards against the game's own bugs only ran online, so someone playing offline could still hit them. They now run offline too.
- **"Error communicating with the server" when sharing a detailed livery.** The game refused to send a design file bigger than half a megabyte, and the biggest designs were just over it. It now sends designs up to four megabytes.
- **Time runs missing on the boards for players who keep their own car packs.** A game with its own car database was refused on every board, even with a stock car. A time run in a car the server knows is now taken, on the Festival Routes board for one. It waits as pending until its ghost arrives, and a ghost that doesn't hold up hides the run. Counters, speed boards and experience still need the standard car database.
