## New server

- The game server and the web services (sign-in, leaderboards, clubs, Drivatars, friends and the rest) now run on a new Go server. It plays the same way as the old one: the new code was checked against the old one with recorded sessions (byte for byte for the game traffic) and with the same requests sent to both for the web services. It uses all CPU cores, so a busy Free Roam world no longer waits on one thread.

## Added

- **Race event toast shows the event name.** The invite toast ("X HAS STARTED A CLASS S1 RACE EVENT") now has the event's track on its second line, in bold: "Festival Drag Race | Press (X) to join". The name comes from the game's own track names, so it appears in your game language.
- **One car select timer for everybody.** In a Free Roam event all players now see the same "Select your car" countdown, which ends at the same moment for everyone. If you pick early you wait on "Waiting for Players" with the time left, so your game starts loading together with the others and the others' cars are not stale when the grid forms.
- **Events hold 12 players.** When 12 are ready the event starts at once, and anyone who would be the 13th stays out of it instead of being sent to the loading screen and thrown back.
- **Hotfixes between releases.** The launcher can install a newer signed FH2MP shim of the same version line without a new launcher, shows the hotfix notice in its message bar, and can switch off a single mod or feature a hotfix names. Releases are signed and an older one served later is refused.
- **HonkHonk 0.4.0** is the pinned version. It no longer hooks the speedometer gauges (the 0xdffe crash) and reads the game's active controller instead of polling XInput (the lobby lag under Wine, #354 and #359).

## Changed

- **A player who does not finish loading an event is dropped alone after 30 seconds.** Before, one stuck loader could take the whole lobby back to Free Roam and the load waited on them much longer. The others start without them.
- **Cars with parts the game does not know no longer inflate class and PI.** The server resets such a car's class and PI to the stock car's, and the event car picker shows that class and PI too, so you are no longer picked into a class you do not fit and kicked afterwards. Car packs keep working in the game as before.
- **Leaderboards:** rows of a car the car database does not know (shown as "DLC Car") are hidden, and new scores with such a car are not accepted. Scores posted with nitrous are refused too, speed zones and traps included.
- **Redline** is no longer reported for running. Only the nitro tool is.
- Free Roam King and Infection end at the time limit the leader set. The server used to end them at 240 seconds while the clients kept playing, so late hits did nothing.

## Fixed

- Launcher on Windows: the setup wizard showing grey space under its page, two pages' buttons on top of each other, and rising up the screen or changing size when moved, which happened after every launcher update (#384). The wizard now has one size for all its pages.
- Cars that lost control of themselves after a collision in traffic: a request from the car's own player is answered with ownership instead of a denial that took the car away.
- A crash in the speedometer (0xdffe) and a crash when the game logs an event for a player it has no record of.
- The launcher crashing at start when it wrote its start line to the log.
- Windows: much less CPU time with many remote cars around. The game spent most of one core checking memory ranges around every read; 29 cars ran at 59-60 fps instead of 25.

## Experimental: Free Roam worlds of up to 75 players

Built, tested only on the dev server, and **off by default**: Free Roam still holds 12 players and a client still shows at most 11 other players' cars, so nothing changes for you in this release.

- The server can hold 12 to 75 players in one Free Roam world (`FH2MP_WORLD_CAPACITY`), including the matchmaker and lobby reservations. Events, Road Trip and Car Meet stay at 12, and an event takes at most 12 players of a bigger world.
- The client can load up to 75 remote cars (`FH2MP_CAR_SLOTS`, with its companion switches), draws the party list past 12 rows and no longer crashes on the 14th car. On dev, one real player in a world with 71 test players had all 72 cars loaded at 60 fps.

## Behind the scenes

- The game server checks its disks when it starts and warns in its log when one is nearly full or a data volume is not mounted. Old crash reports are removed once a day, after 30 days or beyond 10 GB. Backups and reports live on their own volume.
